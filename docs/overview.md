# Project Overview

## Vision
EsportsLyzer is a real-time analytics platform focused on live sports and esports intelligence. The goal is to combine live match data, contextual analysis, and clear visual storytelling into a single dashboard product.

## Product direction
The platform currently emphasizes CS2 and is designed to expand into football and tennis through a modular architecture. The experience is meant to help users understand momentum, probability, performance, and match flow without reading raw data feeds.

## Current maturity
- Active MVP / prototype in progress
- CSAPI match results, player stats, and ranking-based estimates are integrated
- Dashboard UI and 30-second Socket.IO refreshes are in place; the current CS2 provider does not guarantee current-live events
- Football/tennis and personalization have partial service/UI scaffolding; reliable live coverage and persisted preferences remain unfinished

## Core promise
EsportsLyzer turns raw match events into readable decision-support experiences for users who want live insights, not just scores.
