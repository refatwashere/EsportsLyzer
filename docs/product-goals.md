# Product Goals

## Primary objectives
- Deliver real-time, readable match data for esports and sports audiences
- Present probability, highlights, and timeline-based insights in a clear interface
- Enable fast comparison between teams, players, and match states
- Build a platform that scales beyond CS2 into multiple sports
- Keep the product inexpensive to run and easy to deploy

## Core value proposition
The product turns raw match data into usable live intelligence. Instead of displaying isolated numbers, it surfaces context, trends, and momentum changes so users can better understand a match as it unfolds.

## Strategic outcome
The long-term goal is a reusable analytics layer for multiple sports, while keeping the first release focused enough to ship and validate quickly.
