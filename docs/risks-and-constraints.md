# Risks and Constraints

## Data reliability
External APIs may rate-limit, block, or change formats. The project must include resilience, fallback logic, and clear handling for incomplete or delayed responses.

## Prediction accuracy
Analytics are intended as match intelligence, not guaranteed forecasting. The system should remain transparent about uncertainty and evolving models.

## Product scope management
The platform can grow quickly. The team should keep the MVP stable before expanding into broader features and datasets.

## Strategic recommendation
The near-term best approach is to continue improving the CS2-first dashboard while designing the architecture to scale into a wider multi-sport product.
